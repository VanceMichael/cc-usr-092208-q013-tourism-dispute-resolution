# 跨境旅程争议协商

协同处理入境旅程中跨服务商、跨币种的履约争议和退款。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括入境游客、境外组团社、国内文旅服务商、支付机构与调解人员。

资料所依据的领域事实如下：

- 活动聚焦入境旅游企业经营难点与行业流通堵点
- 跨境旅游和跨境支付经验被作为案例分享
- 参与方希望把便利化举措转化为落地成果

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
